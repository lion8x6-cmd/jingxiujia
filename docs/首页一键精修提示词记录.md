# 首页「一键精修」提示词记录

> 用途：记录首页一键精修功能实际调用的提示词，便于查找、对比和后续调整。
> 仅收录**首页一键精修**（默认模板 `t2`「人像美颜」）的提示词，其他功能（局部编辑、快捷调节、一句话改图、调试实验室等）暂不收录。

- **代码位置**：`miniprogram/utils/templates.js` 中 `id: 't2'` 的模板
- **调用入口**：首页「一键精修」按钮 → `pages/index/index.js` 中 `DEFAULT_TEMPLATE_ID = 't2'`
- **使用模型**：豆包 Doubao-Seedream-5.0-pro（图生图）
- **字段说明**：`prompt` 为正向提示词，`negativePrompt` 为负面提示词

## 一、当前版本（2026-08-27 起）——性别自适应版

**改动原因**：旧版提示词偏女生写真向（含口红、白嫩肤色、网红氛围感、瘦脸柔轮廓、纤细身形），男生照片会被涂口红、磨白、轮廓修柔女性化；且写死了"背景木屋和花吧、水体、全身人像"等具体场景，换图即不适用。
**改动思路**：不加 UI、不让用户选性别，在同一条提示词里写性别条件分支，由模型看图自行判断性别走对应修法；多人或难以判断时只做通用精修兜底。

### prompt（正向提示词）

```
你是一位经验丰富、审美好的人像精修师，擅长自然写实修图，保留人物真实辨识度，不做夸张网红脸。

【通用要求·无论男女都执行】
保持原图尺寸比例、人物姿势站位、构图位置、服装款式颜色、背景环境完全不变，不裁切、不扩图、不移动人物。保持人物原本五官和长相，不换脸、不重塑五官；只去除脸部和皮肤的明显瑕疵、痘印、暗沉、油光和粗糙毛孔，保留自然皮肤纹理。严格保持头发的发型、发色、发际线和整体造型完全不变，不重新造型、不改变长短厚薄，仅把少量明显炸毛、翘出的凌乱碎发顺手理顺，不改动原本的发型轮廓。身形只做轻微自然优化，不极端瘦身、不改变服装遮挡关系、不增加裸露皮肤。背景不改变构图景物，分层增强层次、平衡光影、通透写实，景物保留原本固有色、仅适度提升质感，提亮但不过曝、不偏色。若原图中脸部被遮挡、不可见或只有侧脸轮廓，不要生成或补全眼睛、鼻子、嘴等五官，只提亮可见皮肤区域。

【环境调节·无论男女都执行】
· 去除水印：彻底清除图片中已有的一切水印、平台 logo、平台标识、文字贴纸、角标、日期戳和杂乱字幕；被水印覆盖的区域用周围真实的皮肤、衣物或背景纹理自然补全，做到不留痕迹、不糊成一片，同时不要新生成任何文字或水印。
· 闪光灯补光：模拟自然闪光灯对人物进行轻微、均匀的补光，把人物整体亮度提亮到柔光照射的效果，面部受光均匀、肤色通透自然、眼神光清晰，照片质感更干净清晰；但绝不能过亮、过曝，不能出现死白或生硬的闪光阴影，保留真实写真氛围。

【先判断图中人物性别，再按对应方式精修】
· 若为女性：肤色提亮到干净白嫩但不过曝；嘴唇添加自然淡色口红，颜色贴合当前妆造；脸颊与下颌线轻微收窄，瘦脸幅度自然克制；手臂、腰腹、腿部外轮廓轻微修细并拉直，整体显得修长匀称、精致有气质，绝不畸形瘦身。
· 若为男性：以"完全保留本人原样"为最高原则，只做清透肤质的基础精修，不做任何风格化加工。严格保持原图的发型、发色、发际线、眉毛形状、面部轮廓和脸型胖瘦完全不变，不重新造型、不修硬朗轮廓、不刻意打造阳刚/硬朗/粗犷风格。严格保持原图的胡须状态：原图没有胡须或胡渣的，绝不添加络腮胡、八字胡、唇须或任何胡渣，保持干净无须；原图本来有胡须或胡渣的，原样保留其形态与范围，不剃除、不增减、不改形状。只做以下处理：去除痘痘、痘印、油光、暗沉、毛孔粗糙等明显瑕疵，均匀肤色并自然提亮（不惨白、不过度美白），眼神轻微提亮有神，其余五官、毛发、轮廓全部与原图一致。
· 若为多人合影或性别难以判断：只执行上面的通用去瑕疵、均匀肤色、提升画质，不做任何性别专属的妆容或轮廓改动。
```

## 三、本次改动要点速览

| 维度 | 旧版 | 新版 |
|---|---|---|
| 性别适配 | 仅女生向（口红/白嫩/瘦脸/纤细） | 女生走柔美精修；**男生完全保持原样**，只做去痘印/提亮肤色等基础清透处理，不刻意造风格 |
| 男生发型 | 无防护 | 严格保持发型/发色/发际线/眉形，不重新造型（正向+负面双重锁定） |
| 男生胡须 | 无防护（v1 误写"修整齐"导致乱加/乱剃） | 按原图胡须状态锁定：没胡子绝不加络腮胡/八字胡/胡渣；有胡渣原样保留不剃、不改形 |
| 男生轮廓 | 无 | 不磨柔娘化，也不刻意修成硬朗/阳刚/粗犷，脸型轮廓保持原样 |
| 男生防护 | 无 | 负面词禁止：涂口红/浓妆/惨白、凭空加胡须、剃掉原有胡渣、改发型眉毛、改轮廓、过度瘦身 |
| 场景 | 写死"木屋花吧、水体、全身人像、户外写真" | 通用化，不限定具体场景 |
| 多人/不确定 | 无处理 | 兜底：只做通用去瑕疵，不做性别专属改动 |
| 风格 | "精致网红氛围感" | "自然写实、保留真实辨识度" |
| 环境调节 | 无 | 独立区块：去水印（清已有水印/logo/贴纸/角标）+ 闪光灯补光（轻微均匀柔光，不过曝） |

> **男生提示词修订记录（v2）**：v1 男生分支写了"保留胡须只修整齐、轮廓硬朗阳刚"，实测导致①改发型 ②给没胡子的男生加络腮胡/八字胡 ③把原有胡渣弄没 ④刻意打造硬朗通用风格。v2 改为"男生完全保持原样、只做基础清透肤质处理"，胡须/发型/轮廓一律按原图锁定，并在负面词加双向防护（禁止凭空加胡须、禁止剃掉原有胡渣）。

> 备注：性别判断依赖模型识图，极少数情况可能误判；已用"多人/难判断→仅通用精修"做兜底。建议用男生、女生、合影各一张实测效果后再调措辞。
